LLM 连接

OpenAI 兼容接口，例如 OpenAI https://api.openai.com/v1、DeepSeek https://api.deepseek.com/v1、Ollama http://127.0.0.1:11434/v1。

通常以 /v1 结尾，不要带 /chat/completions。
只保存在服务内存，不写盘。
越低越稳、越高越发散，推荐 0.6–0.9。
填好 Base URL 与模型后可以测试。
